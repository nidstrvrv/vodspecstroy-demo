# ВОДСПЕЦСТРОЙ — лаконичная демо-версия

Версия переработана после оценки структуры сайта и реальных фотоматериалов.

## Логика страницы

1. Hero — позиционирование и один сильный реальный кадр.
2. Задача — интерактивный выбор сценария заказчика.
3. Как работаем — сокращенный путь «задача → решение → реализация».
4. Виды работ — основной доказательный блок с реальными фотографиями.
5. Под ключ — полный инженерный цикл без отдельного перегруженного раздела документации.
6. Фото выполненных работ — интерактивная карусель вместо второй большой галереи.
7. Заявка — один основной следующий шаг.
8. Финальный CTA.

Удалены как избыточные отдельные блоки:
- «Вам не нужно быть инженером» — мысль встроена в блок задачи;
- типы объектов — нет подтвержденной привязки фотографий к конкретным объектам;
- большая сетка «практика» — дублировала виды работ;
- отдельная портфолио-сетка — заменена каруселью;
- «Почему ВОДСПЕЦСТРОЙ» — тезисы частично дублировали цикл;
- неподтвержденные метрики XX;
- отдельный массивный блок документации — документация встроена в цикл.

## GitHub Pages
