# ВОДСПЕЦСТРОЙ — демо с реальными материалами

Обновленная версия для показа заказчику.

## Что изменено
- в сайт встроены реальные фотографии выполненных работ;
- визуальные заглушки заменены на реальные материалы;
- секция «Объекты» адаптирована под фактические виды работ, без вымышленных адресов и клиентов;
- добавлена фильтруемая галерея работ;
- сохранен режим комментариев для согласования правок;
- проект готов к публикации на GitHub Pages.

## Папка с фото
`assets/photos/` содержит оптимизированные JPEG-файлы, подготовленные для сайта.

## Важно
Если позже появятся:
- реальные названия объектов,
- города / регионы,
- описания задач и результатов,

их можно будет добавить в отдельные карточки кейсов и страницы проектов без переделки всей структуры.
