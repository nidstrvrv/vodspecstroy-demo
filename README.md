# ВОДСПЕЦСТРОЙ — демо для согласования

Версия предназначена для показа заказчику и сбора правок.

## Встроенный режим комментариев
Заказчик может нажать «Комментарий к разделу» или плавающую кнопку «Оставить правки», сохранить замечания по конкретным блокам, а затем:
- скопировать весь список;
- скачать `vodspecstroy-comments.txt`.

Комментарии хранятся локально в браузере (`localStorage`) и никуда автоматически не отправляются.

## Публикация на GitHub Pages
1. Загрузите содержимое архива в репозиторий.
2. `Settings → Pages → Source → GitHub Actions`.
3. После push в `main` workflow автоматически опубликует сайт.

## Перед production
Замените демо-данные на реальные: телефон, email, адрес, проекты, фотографии, показатели, документы и реквизиты. Подключите CRM/backend и аналитику. Уберите `noindex, nofollow`.
